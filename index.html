Why 18 mm? Sensor distance compared with the tape

Closer than 18 mm (12 to 17 mm)

Both sensors can sit on the black tape at the same time, even when the robot is a little off centre. Both read "black", so the robot does not know which way to turn. It only starts steering once it has moved a few millimetres off centre, so its corrections are gentle and late.

Equal to 18 mm

When the robot is centred, one sensor is over each edge of the tape. As soon as it drifts, one sensor sees more black than the other, so the steering reacts straight away.

Wider than 18 mm (19 to 35 mm)

When the robot is centred, both sensors can be on the white floor, with the tape between them. The robot sees "no line" and can drift off the track, and it can lose the line completely.

Two experiments

Experiment 1: Change the motor speed. Use the competition arena with sensor distance 18 mm. Press Back to start, run for about 90 seconds at motor speed 140, then press Record run. Now set motor speed to 220, go back to start, run again for 90 seconds and record. What happens to the laps and the best lap?

Experiment 2: Change the sensor distance. Keep motor speed at 140 on the competition arena. Record a run at 18 mm, then at 12 mm, then at 35 mm. Watch the "Sees" text and the "times lost" count each time. Which distance keeps the robot on the tape?

Sensors

Each sensor reads how much black it sees. If the left sensor sees more black, the line is on the left.

Steering

The robot compares the two sensors. If the line is on the right, it slows the right wheel and speeds up the left one, so it turns right.

Checkpoints

On the competition arena, the robot must pass CP1, CP2, CP3 and CP4 in order before its lap counts. On the optional tracks, one full lap back to START counts.
